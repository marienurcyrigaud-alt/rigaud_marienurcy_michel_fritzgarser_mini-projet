# Mini-Projet Python : Gestion de Billetterie

## Sujet
Application console en Python permettant de gérer la billetterie d'un événement : réservation de places par zone, annulation, sauvegarde des données au format JSON et affichage du bilan financier et de l'historique.

## Participants
* **Marie Nurcy Rigaud**
* **Michel Fritzgarser**

## Instructions de lancement
1. Assurez-vous d'avoir **Python 3** installé sur votre machine.
2. Téléchargez le fichier `devoir (1).py`.
3. Ouvrez un terminal dans le dossier du projet et exécutez la commande :
   ```bash
   python "devoir (1).py"
   ```

## Exemple d'utilisation
Au lancement du programme, un menu interactif s'affiche :
1. **Réserver des billets** : choisissez la zone et le nombre de places souhaitées ; l'application génère les identifiants de billets et sauvegarde automatiquement dans le fichier JSON.
2. **Afficher le bilan** : consulte les places disponibles par zone, le nombre de billets actifs, les recettes brutes/nettes en GDS et les 5 dernières actions de l'historique.
